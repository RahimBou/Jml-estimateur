# JML Prospection V1

Projet indépendant de prospection immobilière JML Immobilier.

## Objectif V1
- Base de biens/prospects
- Recherche multicritère
- Fiche bien complète
- Statuts commerciaux
- Historique des actions
- Relances
- Import de prospects publics
- Préparation à la carte et aux sources DPE/pige en V2

## Statuts
Nouveau, À contacter, Visité, Pas encore en vente, À relancer, Mandat obtenu, Mandat refusé, Vendu/abandonné.

## Principe de conformité
Les sources doivent rester publiques et licites. La V1 ne doit pas chercher à réidentifier des particuliers à partir de données de compteurs, consommations, comptes personnels ou autres données privées.

## Architecture prévue
Une base locale structurée permettra ensuite de brancher des sources de pige et les données DPE publiques sans changer le modèle commercial.
